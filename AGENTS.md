# Development Rules

## 1. Think Before Coding
Read the relevant code first. State assumptions and clarify requirements when they affect the result.

## 2. Simplicity First
Use existing HTML, CSS, and JavaScript patterns. Avoid new dependencies or abstractions unless necessary.

## 3. Surgical Changes
Change only what the task needs. Preserve existing behavior, localStorage keys, and data compatibility.

## 4. Goal-Driven Execution
Define observable success criteria, verify affected workflows, and report results and remaining issues. Submit changes for review; do not merge automatically.
